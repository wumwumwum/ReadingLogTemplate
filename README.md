# ReadingLogTemplate
This Reading Log Template was created in Drive Sheets. 

# Usage

This template is free to copy and use. 

# Features

The Reading Log features:
* progress bars
* counts for minutes read, pages read, books read, and days spent reading
* counts for different formats for reading (book, ebook, audiobook, journal, and articales)
* goal trackers to help reach your personal reading goals
* automated log statistics using formulas
* a pie chart to graphically show your preferred reading format
* a stylized log that resembles an old book checkout card
* security limitations/ protections on the file

[The Reading Log can be found at this link](https://docs.google.com/spreadsheets/d/1WQmpQeFsIBTaT9w_wOUa4YqLNQOTRsa0MT1274ncWAo/edit?usp=drive_link).
